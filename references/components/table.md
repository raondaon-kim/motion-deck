# 표 (table) 컴포넌트

표가 필요한 슬라이드는 **새로 만들지 않고** 하나의 렌더러(`runtime/src/table.js`)와 하나의 템플릿(`templates/lecture/table.json`)을 데이터만 바꿔서 쓴다. 형태는 `variant`로 고른다.

## 변형

| variant | 언제 | 열 구성 | 자동 처리 |
|---|---|---|---|
| `compare` (기본) | 항목 × 속성 비교 (방법별 방식·장점) | [항목, 속성1, 속성2] | 첫 열 굵게 |
| `matrix` | 기능 × 선택지 가능 여부 | [기능, 선택지1…3] | 칸 `✓ ✗ △`(또는 `O X`)를 손그림 기호로, 가운데 정렬, 데이터 열 균등 폭 |
| `before-after` | 전/후 대비 | [기준, 이전, 이후] | 마지막 열 강조(강조색 머리글·굵은 글자), 이전→이후 화살표, 이전 열은 흐리게 |
| `steps` | 순서 있는 절차 | [단계, 할 일] | 행마다 번호 배지 1, 2, 3… |

공통 옵션: `emph`(강조할 열 번호), `highlight`(테두리 칠 행 번호), 행마다 `at`(큐) → 내레이션이 그 행을 말할 때 등장.

## 가독성 규칙 (자동으로 강제됨)

첫 표를 만들며 손으로 맞췄던 기준을 코드와 검증으로 옮겨 둔 것이다.

| 규칙 | 값 | 어디서 |
|---|---|---|
| 열 수 | 2–3 (matrix 2–4) | `pipeline/tables.py` → 스토리보드 검증 (어기면 LLM이 고침) |
| 행 수 | 2–5 | 〃 |
| 글자 수 | 머리글 ≤ 10자, 첫 열 ≤ 10자, 나머지 ≤ 22자 (문장 아닌 구) | 〃 |
| matrix 칸 | ✓ / ✗ / △ 만 | 〃 |
| 글자 크기 | 머리글 38px, 칸 36px에서 시작 → 상자의 80%를 채울 때까지 최대 1.3배 확대 | `table.js` `tableLayout` |
| 열 폭 | 내용 길이 비례, 각 열 ≥ 표 폭의 18% | 〃 |
| 줄바꿈 | 균형 줄바꿈(마지막 줄에 단어 하나 금지), 행 안에서 세로 가운데 | 〃 |
| 위치 | 상자 안에서 세로 40% 지점(제목 아래에서 읽기 좋게) | 〃 |
| 색 | 팔레트만 사용(머리글 = 파스텔, 강조 = accent) → 대비 보장 | 템플릿 |

## 라이브러리 (`library/table/`)

- `md.py make`가 끝날 때마다 스토리보드의 표 슬라이드를 `library/table/<hash>.json`에 저장한다(같은 내용은 한 번만).
- 다음 강의의 스토리보드 프롬프트에 변형별 최신 예시가 들어간다 — "구조는 변형해서 쓰고 문구는 베끼지 말 것".
- 좋은 표를 직접 추가하려면 같은 형식의 JSON을 넣으면 된다: `{"variant", "title", "columns", "rows", "topic"}`.
- 처음에는 diet-check의 실제 표 1개 + 변형별 참고 표 3개(`project: "seed"`)가 들어 있다.

## 덱에서 직접 쓰기 (파이프라인 밖)

```json
{ "type": "table", "variant": "before-after", "x": 180, "y": 300, "w": 1560, "h": 700, "headColor": "soft3",
  "columns": ["상황", "이전", "AI 활용 후"],
  "rows": [ {"cells": ["기록", "생각날 때만", "식사 전 사진 한 장"], "at": "@c2"},
            {"cells": ["분석", "막연한 느낌", "주간 패턴 요약"], "at": "@c3"} ] }
```
