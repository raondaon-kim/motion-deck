# 그래프 (chart) 컴포넌트

그래프가 필요한 슬라이드는 하나의 렌더러(`runtime/src/chart.js`)와 하나의 템플릿(`templates/lecture/chart.json`)을 **데이터 + variant**만 바꿔서 쓴다. 설계는 dataviz 방법론(형태 → 색 → 검증 → 마크 규격 → 접근성 → 렌더 확인)을 영상(1920×1080)에 맞게 옮긴 것이다.

## 변형

| variant | 데이터의 일 | 데이터 | 자동 처리 |
|---|---|---|---|
| `donut` | 전체 중 비중 | `items [{label, value, at}]` 2~5, `center {value, label}`, `highlight` | 조각 사이 표면색 간격, 강조 조각 살짝 빼기, 오른쪽에 색점+이름+비율 목록(조각과 함께 등장) |
| `bar` | 항목별 크기 / 전후 비교 | `categories` 2~6, `series [{name, values}]` 1~2, `delta` | 둥근 끝(바닥은 직각), 막대 사이 간격, 범례(2계열), 강조 계열 값 표시, `delta`면 앞 계열 회색 + 증감률 |
| `line` | 시간에 따른 변화 | `categories` 3~12, `series` 1~2, `marks [{index, label, at}]` ≤3 | 왼→오 그려짐, 1계열이면 10% 면 채움, 점에 표면색 링, 끝값 표시, 단계 표시(지시선+라벨) |
| `scatter` | 두 지표의 관계 | `points [{label, x, y, at}]` 3~7, `xLabel/yLabel`, `xEnds/yEnds`, `zone {x, y, label, at}` | 강조 영역(10% 채움+테두리), 영역 안 점은 브랜드색·밖은 회색, 라벨 충돌 회피(오른쪽→왼쪽→위→아래) |

공통: `unit`(값 단위), `note`(예: "예시 수치"), `emph`(값을 표시할 계열), 항목마다 `at`(큐) → 내레이션에 맞춰 하나씩 등장.

## 규칙

| 규칙 | 근거 / 위치 |
|---|---|
| **y축은 하나** — 계열 최대 2, 단위가 다르면 그래프를 나눈다 | dataviz 금지 1순위 · `components.py` 검증 |
| **색은 검증된 순서**: 1번 = 브랜드색, 이후 참고 팔레트 순서에서 이웃과 구분되는 색만 (정상 시각 ΔE ≥ 20, 색각이상 ΔE ≥ 8, 부족하면 기준선 15/6까지만 완화) | `palette.py` `chart_series` — 기준색 10개를 `validate_palette.js`로 전부 통과 확인 |
| 팔레트가 모자라면 회색(생성 색 금지) | `chart.js` `ser()` |
| 2계열 이상이면 범례, 값 라벨은 아껴서(강조 계열·끝값·도넛 목록) | dataviz 라벨 규칙 |
| 글자는 잉크색만, 계열 색은 옆의 표시(점·사각형)가 담당 | 〃 |
| 격자선은 실선·옅게, 마크는 얇게 + 둥근 끝 | 〃 (영상 기준 웹 수치의 약 2배) |
| 글자 크기: 축 28px 이상, 라벨 32px, 값 32~40px | `theme.type.caption` 기반, QA `minText` 28 |
| **예시 수치의 정직성**: 원자료에 수치가 없으면 `data_source: "example"` → 화면에 "예시 수치" 표시 + 내레이션에 "예를 들어/예시로"가 없으면 스토리보드 오류 | `deck.py` · `storyboard.py` |

인터랙션(호버·툴팁)은 영상이라 해당 없음. 대신 모든 값은 라벨·목록·축으로 화면에서 읽을 수 있게 한다.

## 덱에서 직접 쓰기

```json
{ "type": "chart", "variant": "bar", "x": 200, "y": 300, "w": 1520, "h": 640, "unit": "분", "note": "예시 수치", "delta": true,
  "categories": [{"label": "메일 회신", "at": "@c2"}, {"label": "회의록", "at": "@c3"}],
  "series": [{"name": "AI 도입 전", "values": [60, 45]}, {"name": "AI 도입 후", "values": [25, 15]}] }
```

## 라이브러리 (`library/chart/`)

완성된 강의의 그래프 구조가 저장되고(큐 제외), 다음 강의 스토리보드에 변형별 예시로 들어간다 — 구조는 변형해서 쓰고 수치·문구는 베끼지 않는다.
